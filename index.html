يلزم ضبط إعداد Firebase

لم يتم إدخال بيانات مشروع Firebase بعد. افتح الملف js/firebase-config.js والصق بيانات مشروعك (config) ثم أعد تحميل الصفحة.

  1. ادخل إلى console.firebase.google.com وأنشئ مشروعًا جديدًا (أو استخدم مشروعًا موجودًا).
  2. من القائمة: Build ← Firestore Database ← Create database واختر وضع Start in production mode ثم عدّل القواعد كما في ملف README.
  3. من Project settings ← General ← Your apps أضف تطبيق ويب </> وانسخ كائن firebaseConfig.
  4. الصق القيم داخل js/firebase-config.js وارفع التعديل إلى GitHub.

التفاصيل الكاملة في ملف README.md داخل المستودع.

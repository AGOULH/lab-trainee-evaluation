# 🧪 نظام إدارة وتقييم متدربي المختبر

نظام ويب عربي (RTL) لإدارة متدربي المختبرات الطبية: التسجيل، توليد الجداول التدريبية تلقائيًا، سجلات الحضور والانصراف (Time Sheet)، تقييم الأقسام، والتقرير النهائي — بيانات سحابية عبر **Firebase Firestore** تعمل من أي جهاز وأي متصفح.

## ✨ المزايا

- **تسجيل المتدربين**: الاسم، رقم الهوية، مدة التدريب (شهران حتى سنة أو مدة مخصصة)، واختيار كل الأقسام أو أقسام محددة.
- **الأقسام السبعة**: Reception · OPD · Chemistry · Hematology · VIRO · Blood Bank · Micro.
- **جدول تدريبي تلقائي**: توزيع المدة بالتساوي على الأقسام المختارة (أحد–خميس، فترة صباحية)، وكل قسم من تاريخ إلى تاريخ.
- **لوحة معلومات**: أعداد المتدربين حسب الفترة (شهر / شهرين / 3 / 6 أشهر)، توزيعهم على الأقسام، والتسجيلات الشهرية.
- **بحث**: بالاسم أو رقم الهوية أو فترة التدريب.
- **Time Sheet للطباعة**: كل شهر في ورقة مستقلة، أيام الأحد–الخميس فقط، بأعمدة التاريخ / وقت وتوقيع الحضور / وقت وتوقيع الانصراف.
- **تقييم الأقسام**: لكل قسم حساب دخول خاص، ويقيّم متدربيه على 6 معايير بدرجات FAIR / GOOD / V.GOOD / EXCELLENT.
- **مسؤول التدريب**: يرى تقييمات كل الأقسام مجمعة، يبحث بالمتدرب أو القسم، ويصدّر التقرير النهائي للطباعة أو PDF.
- **استعلام المتدرب**: يدخل المتدرب رقم هويته من شاشة الدخول ليرى جدوله دون حساب.
- واجهة عربية RTL متجاوبة (جوال + كمبيوتر) مع وضع فاتح وداكن.

## 🚀 التشغيل لأول مرة

### 1) إنشاء مشروع Firebase (مرة واحدة)

1. ادخل إلى [console.firebase.google.com](https://console.firebase.google.com) بحسابك.
2. **Add project** ← اكتب اسمًا مثل `lab-trainee-evaluation` ← أكمل الإنشاء (تحليلات Google اختيارية — يمكن تعطيلها).
3. من القائمة الجانبية: **Build ← Firestore Database ← Create database** ← اختر الموقع الأقرب (مثل `eur3` أو `me-central`) ← **Start in production mode**.
4. افتح تبويب **Rules** والصق القواعد التالية ثم **Publish**:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
```

> ⚠️ هذه القواعد تسمح بالوصول لأي شخص يعرف رابط المشروع، وهي مناسبة للاستخدام الداخلي البسيط. حماية الدخول تتم داخل التطبيق بأسماء المستخدمين وكلمات المرور.

5. من **⚙️ Project settings ← General ← Your apps** اضغط أيقونة الويب **`</>`** ← سجّل التطبيق باسم أي شيء (بدون Hosting) ← انسخ كائن `firebaseConfig`.

### 2) ربط التطبيق

افتح الملف [`js/firebase-config.js`](js/firebase-config.js) والصق قيم مشروعك مكان القيم المؤقتة:

```js
export const firebaseConfig = {
  apiKey: "AIza....",
  authDomain: "your-project.firebaseapp.com",
  projectId: "your-project-id",
  storageBucket: "your-project.appspot.com",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abcdef",
};
```

ارفع التعديل إلى GitHub — وسيعمل الموقع مباشرة.

### 3) النشر على GitHub Pages

1. من صفحة المستودع: **Settings ← Pages**.
2. تحت **Build and deployment**: اختر **Deploy from a branch** ← الفرع `main` ← المجلد `/ (root)` ← **Save**.
3. بعد دقيقة يصبح الموقع متاحًا على: `https://<username>.github.io/lab-trainee-evaluation/`

## 🔑 الحسابات الافتراضية

تُنشأ الحسابات تلقائيًا في Firestore عند أول تسجيل دخول:

| الحساب | اسم المستخدم |
|---|---|
| مسؤول التدريب | `admin` |
| كل الأقسام السبعة | `reception` / `opd` / `chemistry` / `hematology` / `viro` / `bloodbank` / `micro` |

> 🔒 **غيّر كلمات المرور بعد أول دخول** من زر **🔑 تغيير كلمة المرور** في القائمة الجانبية. كل حساب يغيّر كلمته بإدخال الكلمة الحالية، ومسؤول التدريب يقدر يعيد تعيين كلمة أي قسم.

## 🖨️ الطباعة و PDF

أزرار **Time Sheet** و**التقرير النهائي** تفتح نافذة الطباعة مباشرة — اختر طابعة ورقية للطباعة، أو **Save as PDF** لحفظ ملف PDF. كل شهر من الـ Time Sheet يخرج في صفحة A4 مستقلة.

## 🧱 التقنية

- HTML / CSS / JavaScript خالص (بدون أطر عمل) — يعمل مباشرة على GitHub Pages.
- Firebase Firestore (SDK v10) لتخزين المتدربين والتقييمات والحسابات سحابيًا.
- خط IBM Plex Sans Arabic، تصميم متجاوب مع وضع فاتح/داكن.

### بنية البيانات في Firestore

| المجموعة | المحتوى |
|---|---|
| `trainees` | بيانات المتدرب + الجدول التدريبي المولّد |
| `evaluations` | تقييم واحد لكل (متدرب × قسم) بمعرّف `traineeId_dept` |
| `users` | حسابات الأقسام ومسؤول التدريب (كلمات المرور مخزنة SHA-256) |
